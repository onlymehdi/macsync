Your Mac,
the same everywhere.

Sync your Dock, apps and settings across all your Macs through iCloud. Set up a new Mac in minutes, not days.

brew install onlymehdi/tap/macsync

Early release. Works with MacBook Air, Mac Studio, Mac Pro and any other Mac.

How it works

Three steps. No terminal skills needed beyond one install line.

1

Push

On your main Mac, save your Dock layout and installed apps to iCloud Drive.

2

Pull

On a new Mac, pull the snapshot. Missing apps install and the Dock rebuilds in the same order.

3

Done

Same apps, same Dock, same settings on every Mac you own.

Lives in Raycast too

The same commands are available from the Raycast bar. The extension is in the repo's raycast folder.

macsync push        # save this Mac
macsync pull        # apply on a new Mac
macsync pro-push    # save settings (Pro)
macsync pro-pull    # apply settings (Pro)

Pull replaces your whole Dock. Apps that need a login or license key still need a manual sign-in. Some settings need a log out to fully apply.
